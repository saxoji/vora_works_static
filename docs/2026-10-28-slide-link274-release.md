# VORA SLIDE 1.0.4 다운로드 연결

상태: 세 OS의 최종 설치 파일 검수와 S3/CDN 게시, 정확한 카탈로그 준비 마커 게시, metadata-only 빌드를 완료했다. STATIC main 반영과 운영 배포를 진행하며 실제 사이트 적용 결과는 완료 후 아래에 기록한다.

## 변경 내용

편집 캔버스의 Ctrl/Cmd+클릭과 우클릭 하이퍼링크 열기, 일반 도형의 동작 버튼 설정을 보강했다. 1.0.4에서는 같은 프레임에 들어온 포인터 이벤트의 Ctrl/Command 상태도 확인해 내부 장표 이동이 누락되는 문제를 수정했다.

Esc로 그리기를 종료하고, 전환·애니메이션 선택 시 바로 미리보기로 이어지도록 했다. 댓글 패널, 동영상 입력·재생, 사진 앨범, 명령 검색과 파일 선택도 개선했다. 공통 메뉴·JSON·MCP 명령을 맞추고 미지원 화면 캡처·번역 리본을 제거했다.

Windows 녹화는 동기식 MP4 Finalize 성공 후 부적절한 추가 Flush가 실패를 만들던 경로를 수정했다. Finalize와 실제 결과 파일 검사를 통과해야 저장 완료로 처리한다. 카메라 프레임과 발표 녹화의 안내를 구분하며, 미지원 장치 기능을 가능한 것처럼 표시하지 않는다.

## 버전과 소스

- 설치형 버전: macOS arm64, Windows x64, Linux x64 모두 `1.0.4`.
- 세 OS 공통 소스: `93f660b516a272fc6bfe881040fc832ebb3ac479`.
- 카탈로그 게시 시각: `2026-10-28T23:28:12.312583+00:00`.

기존 설치형 기능과 오프라인 서식·글꼴을 보존했다. 설치 파일은 버전별 불변 경로를 사용하며 이전 1.0.2와 공개된 macOS·Linux 1.0.3 파일을 덮어쓰지 않는다. Windows 1.0.3은 공개 승인되지 않았으며, 이전 1.0.3 카탈로그 후보는 대체돼 이번 게시에 사용하지 않는다.

## 검증 범위

- macOS 1.0.4 서명 앱에서 첫 화면, 일반 Cmd+클릭에 따른 내부 슬라이드2 이동, modifier 해제 뒤 목적지 화면과 선택 상태, 정상 종료를 확인했다. 이 검수에서 외부 브라우저·우클릭을 다시 실행하지 않았다.
- Linux 1.0.4 AppImage의 일반 클릭·Ctrl 외부 링크·내부 장표 이동·Undo·정상 종료와 소유 브라우저 정리를 확인했다. 실행은 `40764739476`이다. 변경되지 않은 우클릭 경로는 이전 1.0.3의 `40732339132` 근거를 구분해 재사용했다.
- Windows 1.0.4 MSI 설치·실행 파일 확인·일반 Ctrl 링크 근거를 같은 실행 파일에 연결했다. 잔여 녹화·저장 검수는 `40786370875`에서 완료했다. 실제 앱이 저장한 MP4는 28.1805초, 1280×720, 119프레임이며 전체 영상·오디오 디코딩을 통과했다. 저장 대화상자, 편집 복귀, encoder 종료와 앱 정상 종료를 확인했다. 영상의 모든 프레임을 육안 검수했다는 의미는 아니다.
- 이번 STATIC 전환은 세 OS 최종 승인·게시 영수증과 61개 연결 증거 파일의 원문 해시를 확인했다. 설치 파일과 기존 검사를 다시 내려받거나 실행하지 않았다.
- 앞서 통과한 메뉴 UI 17개·MCP 2개·connected MCP 1개, 웹의 새 번들·IME·작은 Next Ctrl 클릭·동작 설정·미지원 메뉴 제거·카메라 안내 근거는 해당 소스의 기존 결과로 재사용한다.
- STATIC 설정 6개와 release/source 23개, 한국어·영어·일본어, 데스크톱 라이트·모바일 다크·390px 화면, 언어 변경 시 OS 안내 유지 검사는 변경되지 않은 코드의 기존 근거를 재사용한다. 이번 배포 후에는 새 다운로드 데이터와 링크·피드만 확인한다.

이는 모든 메뉴를 실제 OS 창에서 전수 실행하거나 전체 Office 문서·글꼴의 완전 일치를 보증하는 기록이 아니다. 장치 카메라·마이크 캡처를 검증했다는 의미도 아니다. 검수는 소유 합성 문서와 전용 브라우저 프로필로 수행했으며 사용자 문서·프로필을 변경하지 않았다.

## STATIC 통합과 공개

검증된 SLIDE 다운로드 개선 3개를 최신 STATIC `0267c91`까지 안전하게 통합했다. WORD 1.0.4, HWP 1.0.5, CELL 1.0.6의 기존 카탈로그와 다른 제품 파일을 보존했다. 원래 작업 폴더의 미커밋 문서도 그대로 유지한다.

사이트는 기존 metadata-only 빌드를 유지해 대용량 설치 파일을 다시 내려받지 않는다. 단일 publisher가 정확한 최종 카탈로그 해시의 ready marker를 게시한 후에만 빌드·main push·Render 배포를 진행한다. 버전별 manifest와 stable 피드는 STATIC 빌드가 생성하며 별도 S3 stable 쓰기는 추가하지 않는다. 배포 후 한국어·영어·일본어의 1.0.4 버전·세 파일 링크와 업데이트 피드를 확인한다.

최종 카탈로그 SHA256은 `cc185c60b841d431dcf8d714505bbe29b51d6ca6a100346576a6c88735eca74a`다. 정확한 ready marker의 CDN 응답과 metadata-only 빌드 성공을 확인했다. 생성된 stable·1.0.4 manifest가 카탈로그와 일치하고 한국어·영어·일본어 페이지 각각 세 OS 링크를 갖는지 확인했다. 설치 파일 다운로드와 기존 광범위 검사는 반복하지 않았다. 운영 Render 및 실제 페이지 결과는 완료 후 기록한다.
