# VORA SLIDE 1.0.3 다운로드 연결

상태: 설치 파일 준비 중. 현재 공개 버전은 1.0.2를 유지한다.

설치형 후보는 `a5027319c3fadfbf6cc45d1afb3d65ae263dbc07`이며,
기존 C7 설치형 기능을 보존하고 편집 캔버스 Ctrl/Cmd+클릭과
‘하이퍼링크 열기’를 추가한다. 새 파일의 실제 실행·해시·S3/CDN 확인이
끝난 뒤에만 catalog, 준비 marker, 공개 다운로드 페이지를 갱신한다.

## 사이트 변경과 검사

- SLIDE Windows의 `.env.defaults`와 `.env.example`을 기존 Render 설정과
  동일한 `/downloads/slide/?os=windows` 주소로 맞췄다.
- 다운로드 페이지 언어 변경 시 OS·명시 언어·앵커를 유지한다.
- 설정 검사 6개 및 기존 release/source 검사 23개 통과. 변경된 브라우저
  스크립트의 구문과 `git diff --check`를 확인했다.
- 실제 브라우저에서 한국어·영어·일본어, 데스크톱 라이트와 모바일 다크
  화면을 확인했다. 390px 화면의 가로 넘침이 없으며, Windows 안내에서
  영어로 바꿔도 Windows 안내가 열린 상태다.
- 로컬 미리보기에서 운영 stable feed를 가져올 때 CORS가 차단된다.
  이때 사전 생성된 기존 다운로드 링크가 유지됨을 확인했다. 운영의
  동일 출처 요청 장애로 일반화하지 않는다.
- 웹 빌드는 기존 metadata-only 배포를 유지하며 설치 파일을 내려받지 않는다.
  다른 제품의 catalog, 과거 설치 파일, 서명·공증을 변경하거나 반복하지 않는다.

브라우저 증거는 로컬 `output/playwright/`에 보존한다. 설치형 공개 및
STATIC 배포 결과는 실제 완료 후 이 기록에 추가한다. SLIDE 웹 서비스
배포 상태 확인은 사용자의 중단 지시를 유지한다.
